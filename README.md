# Civil 3D MCP — instaladores

Pacotes prontos do **Civil 3D MCP** (Engeplus) para Civil 3D 2023 e 2027.

## Instalar

1. Baixe o `.zip` da [última versão](../../releases/latest).
2. Descompacte, **feche o Civil 3D** e dê dois cliques em `Instalar.cmd` (não precisa de administrador).
3. Reinicie o Claude Desktop e abra o Civil 3D.

Requisito: [Node.js LTS](https://nodejs.org).

## Atualizar

Menu Iniciar → **Civil 3D MCP - Verificar atualizacoes**. Ele consulta este repositório, mostra as novidades e instala a versão nova.
